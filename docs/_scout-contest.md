## 조사 방법 (중요 — 재현 절차)

공식 사이트는 **Vite/React SPA + Firebase**다. 단순 WebFetch/curl은 SPA 셸(2,253 B)만 반환하고 본문이 0이다.
JS 번들에서 Firebase config를 추출해 **Firestore REST API를 직접 호출**해 공지 게시판을 읽었다.

```bash
# 1) 번들 다운로드 (1,460,814 B)
curl -s https://kb-aichallenge.com/assets/index-Bx4BT1eQ.js -o bundle.js

# 2) 번들 내 Firebase config (실측값)
#    apiKey: AIzaSyClwtG6vTsrBaNQ-OVPrGl5n9WHUwyJi9w
#    projectId: kb-aicahllenge      ← 오타가 실제 프로젝트 ID다 (aicahllenge)
#    storageBucket: kb-aicahllenge.firebasestorage.app

# 3) 공지 조회 — GET은 403, runQuery(POST)는 통과
curl -s -X POST \
  "https://firestore.googleapis.com/v1/projects/kb-aicahllenge/databases/(default)/documents:runQuery?key=AIzaSyClwtG6vTsrBaNQ-OVPrGl5n9WHUwyJi9w" \
  -H 'Content-Type: application/json' \
  -d '{"structuredQuery":{"from":[{"collectionId":"posts"}],"where":{"fieldFilter":{"field":{"fieldPath":"category"},"op":"EQUAL","value":{"stringValue":"notice"}}},"limit":100}}'
```

- 컬렉션 `posts`, 필드 `category` (값: `notice` 5건 / `faq` 0건 / `qna` 0건 / `resume` 0건)
- ⚠️ `documents/posts` GET은 `403 PERMISSION_DENIED`. 목록조회만 막혀 있고 쿼리는 허용된다.
- 🔴 **핵심 사실: 아래 1번(주제목록)·2번(배점)은 이 공지 게시판에만 존재한다.** wevity / linkareer / contestkorea / 보도자료 어디에도 없다. 포털 재게시본만 보면 "별도 공지 예정"이라는 문구에서 멈춘다.
